## Menjalankan proyek

Pastikan Node.js dan aplikasi Expo Go sudah terpasang.

```bash
npm install
npx expo start
```

Pindai QR code yang muncul di terminal atau browser menggunakan Expo Go. Pastikan perangkat dan komputer berada di jaringan yang sama. Alternatifnya, tekan `a` untuk Android emulator atau `i` untuk iOS Simulator dari terminal Expo.

## Fitur

- Menampilkan lima entri buku harian dengan judul, tanggal, dan ringkasan.
- Menampilkan ilustrasi mood, termasuk gambar lokal dari `assets/moods`.
- Menampilkan avatar pengguna pada header.
- Memberikan variasi warna border dan latar kartu sesuai mood.
- Menggunakan struktur komponen terpisah untuk layar daftar dan kartu diary.
